# Project Statement

## Problem Statement

When seats are managed manually, it is easy to lose track of which seats
are free. There is also a chance of giving the same seat to two people.
This project provides a small Python system that keeps track of bookings.

## Scope

The current version can:

- show the seat layout
- book a seat
- stop duplicate seat bookings
- cancel a booking
- search for a booking
- display all bookings
- save booking information locally

The program is designed for a small event, classroom, movie screening or
similar situation. It is not intended to be a full commercial booking
platform.

## Target Users

The system can be used by someone managing seats for a small event or by a
student learning how a booking system works.

## High-Level Features

1. Seat layout
2. Booking
3. Booking ID generation
4. Duplicate-seat prevention
5. Cancellation
6. Search
7. Booking list
8. JSON storage
9. Input validation
10. Automated testing
